# 模型文档

> 包含模型概述、训练与推理环境、模型算力、再训练方法、验证方法、导出方法，以及模型类成果要求的对应说明。

## 1. 模型概述

本系统包含两个结构相同、输入与预测目标不同的深度学习模型：

| 模型 | 预测目标 | 权重文件 | 输入维度 | 时间窗 | 参数量 | 权重大小 |
|---|---|---|---|---|---|---|
| TD 模型 | 温度偏差（℃） | `模型权重/温度偏差预测/gru+小波+eca/Model_GRUWavelet_no_leakage_pytorch.pth` | 8 | 36 步（3 小时） | 53,124 | 约 0.203 MB |
| THI 模型 | 温湿指数 | `模型权重/THI/Model_GRUWavelet_no_leakage_pytorch.pth` | 7 | 36 步（3 小时） | 52,738 | 约 0.201 MB |

模型基类结构：**ECA 通道注意力 → 单层 GRU（hidden=128）→ Dropout(0.3) → 全连接输出 1 维回归值**。

检查点中保存了模型配置与归一化器：

- `input_dim`、`time_step`、`feature_names`、`original_features`
- `wavelet='db4'`、`level=3`、`wavelet_window=36`
- `wavelet_target_col`：TD 模型为 `温度偏差`，THI 模型为 `THI`
- `feature_scaler`、`target_scaler`：`MinMaxScaler`
- `no_data_leakage=True`

## 5. 如何再训练模型

### 5.1 前提条件

1. 已按 `02_部署文档.md` 配好环境；
2. 已准备好训练数据 CSV（推荐 `数据/温湿度数据111.csv`），字段与 `05_数据与数据字典.md` 一致；
3. 数据按时间顺序排列，且有 `温度偏差` 与 `THI` 列。

### 5.2 再训练流程

```text
准备数据 → 缺失值处理 → 滑动窗口小波分解 → 划分训练/验证/测试
→ 仅在训练集拟合 MinMaxScaler → 构造时序样本 → 训练（Adam+MSE+早停）
→ 测试集评估 → 保存 checkpoint(.pth)
```

### 5.3 执行命令

本项目的训练脚本不是命令行参数驱动，而是**直接修改脚本顶部常量后整体执行**：

```bash
# TD 模型
python 源码/温度偏差预测/gru+小波+eca/gru.py

# THI 模型
python 源码/THI/gru.py
```

执行前请在脚本中确认/修改：

- 数据文件路径；
- `time_step = 36`、`pred_offset = 6`；
- `wavelet='db4'`、`level=3`；
- `epochs=200`、`lr=0.001`、`batch_size=32`、`dropout=0.3`；
- 输出 `.pth` 文件名与目录。

> 可复现性提醒：原脚本的 `set_seed` 调用被注释掉了。若需要严格复现实验，请取消注释并固定 seed。

### 5.4 训练监控

训练过程会打印每个 epoch 的 `Train Loss` 与 `Val Loss`；早停触发时会恢复最佳权重。建议把终端输出保存为日志：

```bash
python 源码/温度偏差预测/gru+小波+eca/gru.py > train_td.log 2>&1
```

### 5.5 验证方法

| 阶段 | 指标 |
|---|---|
| 训练/验证 | MSE Loss |
| 测试集 | R2、MAE、RMSE、MAPE |
| 预警层面 | TD 三分类 Accuracy/Precision/Recall/F1；THI 四分类同上；综合预警二分类 |

验证脚本：

## 6. 如何导出模型

### 6.1 当前导出方式

训练脚本使用 `torch.save` 保存完整检查点：

```python
torch.save({
    'model_state_dict': model.state_dict(),
    'input_dim': input_dim,
    'time_step': time_step,
    'feature_names': feature_names,
    'wavelet': 'db4',
    'level': 3,
    'wavelet_window': time_step,
    'wavelet_target_col': target,
    'feature_scaler': feature_scaler,
    'target_scaler': target_scaler,
    'no_data_leakage': True,
}, 'Model_xxx_pytorch.pth')
```

### 6.2 加载方式

```python
import torch
from warning_simulation_v2 import GRUWaveletECA

ck = torch.load('模型权重/THI/Model_GRUWavelet_no_leakage_pytorch.pth',
                map_location='cpu', weights_only=False)
model = GRUWaveletECA(ck['input_dim'], 128, 1, 0.3)
model.load_state_dict(ck['model_state_dict'])
model.eval()
```

### 6.3 导出为 TorchScript（可选）

```python
dummy = torch.randn(1, ck['time_step'], ck['input_dim'])
traced = torch.jit.trace(model, dummy)
torch.jit.save(traced, 'model_ts.pt')
```

### 6.4 导出为 ONNX（可选）

```python
torch.onnx.export(
    model, dummy, 'model.onnx',
    input_names=['input'], output_names=['output'],
    dynamic_axes={'input': {0: 'batch'}, 'output': {0: 'batch'}}
)
```

> ONNX / TorchScript 导出命令为建议方案，当前归集包中未提供导出产物。
