# 毕业生项目成果归集包

项目：**鸡舍环境实时滚动预测与双指标预警系统（Wavelet-ECA-GRU）**

本目录依据《毕业生项目系统等成果归集要求》整理。所有文档均为可编辑 Markdown；源码、数据、模型权重、结果图已从原项目复制到本包，**原项目文件未被移动或删除**。

## 快速开始

```bash
# 1. 建议使用 conda 环境（本机已验证：Python 3.10.19）
conda create -n chicken_warn python=3.10
conda activate chicken_warn
pip install -r requirements.txt

# 2. 运行主预警仿真脚本
python 源码/warning_simulation_v2.py

# 3. 运行评估脚本
python 源码/eval_warning_v2.py
```

> 注意：`源码/warning_simulation_v2.py` 中数据文件路径为硬编码的
> `D:\resources\pythonTest\Total - 副本 - 副本\最后三天测试.csv`，
> 运行前请先按 `02_部署文档.md` 修改为你本机的实际路径。
