环境状态判别规则：
若 V(t) ∈ [L(a), U(a)]，则状态为正常
若 V(t) < L(a) 或 V(t) > U(a)，则状态为异常

其中：V(t) = 时刻t的监测值
L(a) = 日龄a对应的下限
U(a) = 日龄a对应的上限

⚠️ 实时预警策略

🎯 预测参数配置

时间步长 5分钟（固定间隔）
输入窗口 36个时间步 = 180分钟历史数据
预测范围 6个时间步 = 30分钟未来数据
滚动更新 每5分钟更新一次预测

温度偏差 (TD)

±2.5℃
预警阈值

温湿度指数 (THI)

74-82
分级阈值

TD预警规则

偏热预警 当预测TD > 2.5℃时触发
偏冷预警 当预测TD < -2.5℃时触发
正常状态 当-2.5℃ ≤ TD ≤ 2.5℃时

THI风险分级

舒适
THI ≤ 74
警戒
74 < THI ≤ 78
预警
78 < THI ≤ 82
危急
THI > 82
预测公式：
TD^(t+6) = f_TD(X_t)
THI^(t+6) = f_THI(X_t)

其中：X_t = 最近36个时间步的历史数据
f_TD, f_THI = Wavelet-ECA-GRU模型

🔄 系统数据流程

多源数据采集 - 巡检机器人、舍内固定点、室外监测点同步获取环境参数
时间戳对齐 - 将多源数据按时间戳对齐，重采样为5分钟等间隔序列
特征工程 - 小波分解、归一化处理，构造36步输入窗口
模型推理 - Wavelet-ECA-GRU模型预测未来30分钟的TD和THI
预警生成 - 阈值判别、风险分级、输出预警信息和调控建议

⭐ 系统优势

  • 提前预测 - 提前30分钟识别环境异常，为环境调控提供决策依据
  • 双指标融合 - 从环境控制偏差(TD)和综合热环境风险(THI)两个维度评估
  • 实时滚动 - 每5分钟更新一次预测，与采样节拍一致，无延迟
  • 模型融合 - 结合小波分解、ECA注意力机制和GRU时序学习
  • 日龄自适应 - 根据肉鸡不同生长阶段自动调整环境适宜范围
  • 可视化展示 - 环境分布差异分析，动态监测与可视化展示
  • 可解释性强 - 清晰的阈值规则和预警等级，便于理解和操作
