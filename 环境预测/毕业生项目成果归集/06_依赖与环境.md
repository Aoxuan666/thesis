## 2. 环境搭建

```bash
# 创建环境
conda create -n chicken_warn python=3.10 -y
conda activate chicken_warn

# 安装依赖
pip install -r requirements.txt

# 验证
python -c "import sys,torch,pandas,numpy,sklearn,pywt,matplotlib; print(sys.version); print(torch.__version__)"
```

无 GPU 的机器：

```bash
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
```
