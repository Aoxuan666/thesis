# 学习文档

> 面向刚接手本项目的研究生或评审老师：用最短路径理解这个课题在做什么、关键名词是什么意思、代码该从哪里读起。

## 1. 一句话理解课题

用鸡舍最近 3 小时的环境数据，提前 30 分钟预测温度偏差 TD 和温湿指数 THI，再按阈值判断鸡舍是否偏热、偏冷或 THI 风险过高，从而提前预警。

## 2. 核心名词

| 名词 | 全称/含义 | 通俗解释 |
|---|---|---|
| TD | Temperature Deviation | 当前温度比目标温度高了多少或低了多少，单位℃ |
| THI | Temperature Humidity Index | 把温度和湿度合成一个“体感热不热”的指标 |
| GRU | Gated Recurrent Unit | 一种适合处理时间序列的神经网络，比 LSTM 更轻 |
| ECA | Efficient Channel Attention | 让模型自动判断哪些输入特征更重要 |
| 小波分解 | Wavelet Decomposition | 把一条时间序列拆成“大趋势”和“多尺度波动” |
| db4 / level=3 | 小波基函数 / 分解 3 层 | 本项目使用的具体小波配置 |
| MinMaxScaler | 最小-最大归一化 | 把不同量纲的数据缩放到 [0,1] |
| no_data_leakage | 无数据泄漏 | 分解时只用历史窗口，不偷看未来数据 |
| time_step=36 | 36 个时间步 | 每步 5 分钟，36 步 = 3 小时历史 |
| pred_offset=6 | 提前 6 步 | 6 步 = 30 分钟，即提前半小时预警 |
| checkpoint | `.pth` 权重文件 | 训练好的模型参数和配置打包文件 |
| scaler | 归一化器 | 预测新数据时必须用训练时保存的 scaler，不能重新拟合 |

## 4. 从 main() 开始读代码

`源码/warning_simulation_v2.py` 的 `main()` 大致分 6 步：

1. 指定数据文件与两个模型文件路径；
2. `load_data()` 读取 CSV；
3. `load_model()` 加载 TD、THI 两个模型；
4. `make_wavelet_features()` 对目标列做小波分解；
5. `batch_predict()` 批量推理；
6. `classify_td()` / `classify_thi()` 判级，`plot_results()` 出图，写日志 CSV。

## 6. 常见误区

| 误区 | 正确理解 |
|---|---|
| 把 `.pth` 当普通模型文件直接 `torch.load` 后就能预测 | 还需按检查点配置实例化模型并加载 `state_dict` |
| 重新用新数据 fit 一次 scaler | 错误。必须用训练时保存的 `feature_scaler` / `target_scaler` |
| 认为 THI 越高越好 | THI 越高越热，风险越高 |
| 认为 Accuracy=1.0 说明模型完美 | 当前预警样本几乎全为正类，指标失真 |
| 直接运行 `gen_framework.py` | 该文件残缺，无法运行，应使用 `make_svgs.py` |
| 把 `.idea` 删了以为代码坏了 | `.idea` 只是 IDE 配置，与代码运行无关 |
