# 环境预测

肉鸡养殖舍环境监测与预警项目的代码、数据与成果材料，内容包括温度偏差（TD）与温湿指数（THI）的深度学习预测、双指标预警仿真，以及论文配图与毕业成果归集文档。

## 目录结构

| 路径 | 说明 |
|---|---|
| `warning_simulation_v2.py` | 预警仿真主程序：滚动窗口读取环境数据，用模型预测 TD/THI，按日龄阈值判定偏热/偏冷与 THI 四级预警，输出结果图与日志 |
| `eval_warning_v2.py` | 评估脚本：读取仿真日志，重算等级并输出回归指标与预警分类指标 |
| `calc_warning_metrics.py` | 精简版指标计算（Precision/Recall/F1/Accuracy 与混淆矩阵） |
| `monitoring_warning_system.py` | 阈值规则库：日龄对应的温湿度/风速/CO2 区间、TD 与 THI 判定规则 |
| `monitoring_system.html` | 网页版监测与预警展示页 |
| `correlation_analysis.py`、`plot_weekly_data.py` | 相关性分析与一周环境数据绘图 |
| `multi_model_comparison_final.py` | 多模型同测试集对比（LSTM/TCN/GRU 及小波、ECA 组合） |
| `make_svgs.py`、`svg_parts.py`、`picture.py` | 论文矢量图与框架示意图生成 |
| `THI/` | THI 预测模型（GRU、LSTM、TCN、Wavelet-ECA-GRU 等各版本） |
| `温度偏差预测/` | 温度偏差预测模型（同上各版本） |
| `预警测试/` | 预警流程测试与评估脚本、模型权重 |
| `相关性分析/` | 变量相关性分析脚本与结果 |
| `毕业生项目成果归集/` | 按学位成果归集要求整理的文档包（开发/部署/使用/模型/数据/环境等） |
| `备用/`、`数据图片/` | 数据备份与配图素材 |

## 运行环境

- Python 3.11（conda 环境 `chicken_warn`）
- 主要依赖：`torch`、`numpy`、`pandas`、`scikit-learn`、`matplotlib`、`PyWavelets`、`xgboost`、`joblib`
- 精确版本见 `毕业生项目成果归集/requirements.txt`

虚拟环境 `venv/` 未纳入版本库，复现时请按上述依赖自行安装。

## 快速开始

```bash
pip install -r 毕业生项目成果归集/requirements.txt
python warning_simulation_v2.py     # 运行预警仿真
python eval_warning_v2.py           # 计算评估指标
```

## 说明

- 环境数据采样间隔 5 分钟，预警目标为提前 30 分钟给出提示。
- 主程序阈值口径为 70/76/81，`monitoring_warning_system.py` 规则库为 74/78/82，两者尚未统一，引用指标时请注明所用口径。
- 高清结果图 `warning_simulation_result.tiff`（约 105MB）超出 GitHub 单文件限制，未上传；同内容 PNG 已保留。
