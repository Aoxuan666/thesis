# 部署文档

> 面向对象：具有软件开发或 Python 环境配置经验的人员。按本文步骤可在本机复现运行环境并启动预警仿真与评估流程。

## 1. 部署目标

本项目不是 Web 服务，没有 Tomcat/Nginx/数据库部署环节。所谓“部署”是指：

1. 准备 Python 环境与依赖；
2. 放置源码、数据、模型权重；
3. 修正脚本中的路径配置；
4. 运行仿真脚本生成结果，再运行评估脚本生成指标。

部署完成后应能在本地得到 `warning_simulation_log.csv`、四子图 PNG/TIFF，以及 `warning_metrics_result.csv`。

## 2. 环境概述

### 2.1 硬件要求

| 项目 | 最低要求 | 推荐 |
|---|---|---|
| CPU | 2 核 | 4 核及以上 |
| 内存 | 4 GB | 8 GB 及以上 |
| 硬盘 | 1 GB 可用空间 | 5 GB 及以上（TIFF 结果约 105 MB） |
| GPU | 不强制 | 有 CUDA GPU 可加速模型推理 |

### 2.2 软件要求

| 软件 | 版本 | 说明 |
|---|---|---|
| 操作系统 | Windows 10/11 或 Ubuntu 22.04 LTS | 本机验证环境为 Windows |
| Python | 3.10.19 | 使用 Anaconda/Miniconda 管理 |
| conda | 任意较新版本 | 用于创建 `chicken_warn` 环境 |
| PyTorch | 2.10.0+cu126 | 无 GPU 时可装 CPU 版 |
| pandas / numpy / scikit-learn | 2.3.3 / 2.2.5 / 1.7.2 | 见 `requirements.txt` |
| PyWavelets | 1.8.0 | 小波分解 |
| matplotlib / seaborn | 3.10.8 / 0.13.2 | 绘图 |

> 当前工作区自带的 `venv` 目录指向其他用户的 Python 路径，**不可直接使用**；请新建 conda 环境。

## 3. 准备工作与依赖安装

### 3.1 创建环境

```bash
conda create -n chicken_warn python=3.10 -y
conda activate chicken_warn
```

### 3.2 安装依赖

在本归集包根目录执行：

```bash
pip install -r requirements.txt
```

`requirements.txt` 中版本来自本机已验证环境。若机器无 NVIDIA GPU，可先安装 CPU 版 PyTorch：

```bash
pip install torch --index-url https://download.pytorch.org/whl/cpu
```

### 3.3 文件放置

建议把本归集包整体放到一个无中文空格冲突的路径，例如：

```text
D:\projects\chicken_warning_delivery\
```

保持目录结构：

```text
源码/         warning_simulation_v2.py 等
数据/         各 CSV
模型权重/     各 .pth / .pkl
图文/         框架图与结果图
```

## 4. 配置文件与路径修改

主脚本 `源码/warning_simulation_v2.py` 中有两处需要关注：

```python
# 第 575 行附近
data_file = r'd:\resources\pythonTest\Total - 副本 - 副本\最后三天测试.csv'

# 第 576~577 行
td_model_file = os.path.join('温度偏差预测', 'gru+小波+eca', 'Model_GRUWavelet_no_leakage_pytorch.pth')
thi_model_file = os.path.join('THI', 'Model_GRUWavelet_no_leakage_pytorch.pth')
```

请改为本包内的相对路径或从包根目录启动后的正确路径，例如：

```python
data_file = r'数据\最后三天测试.csv'   # 若该文件已按归集要求恢复
td_model_file = os.path.join('模型权重', '温度偏差预测', 'gru+小波+eca', 'Model_GRUWavelet_no_leakage_pytorch.pth')
thi_model_file = os.path.join('模型权重', 'THI', 'Model_GRUWavelet_no_leakage_pytorch.pth')
```

> 说明：当前包中 `最后三天测试.csv` 因此前清理已不在工作区；代码原本指向另一个目录的副本。若需运行主脚本，请先从回收站恢复该数据，或改指向任意符合字段要求的 CSV。

无需 `.env`、`application.yml` 等配置文件；阈值写在 `源码/monitoring_warning_system.py` 与 `warning_simulation_v2.py` 中。

## 5. 部署步骤

### 5.1 启动顺序

本系统没有微服务或多模块后台进程，不需要按顺序启动多个服务。推荐执行顺序：

```bash
# 1. 检查 Python 与依赖
python -c "import sys,torch,pandas,numpy,sklearn,pywt,matplotlib; print(sys.version, torch.__version__)"

# 2.（可选）查看模型权重结构
python 源码/inspect_ckpt.py

# 3. 运行主仿真与预警
python 源码/warning_simulation_v2.py

# 4. 运行评估
python 源码/eval_warning_v2.py

# 5.（可选）生成论文配图
python 源码/make_svgs.py
```

### 5.2 数据库准备

无数据库，无需执行 SQL、Restore 或 Navicat 迁移。

### 5.3 Web 服务器

无后端服务，无需 Tomcat/Nginx。静态页面 `源码/monitoring_system.html` 可直接用浏览器打开查看展示效果。

### 5.4 容器化配置

未提供 Dockerfile / docker-compose.yml。如需容器化，可使用如下思路（未验证）：

```dockerfile
FROM python:3.10-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .
CMD ["python", "源码/warning_simulation_v2.py"]
```

注意容器内需要额外安装中文字体，否则 matplotlib 中文会显示为方块。

## 7. 部署注意事项

- 首次运行会重建 `__pycache__`，属正常现象；
- `torch.load(weights_only=False)` 会反序列化对象，只加载本项目提供的权重；
- matplotlib 需要中文字体（如 SimHei / Microsoft YaHei），Linux 下需自行安装字体或修改 `matplotlib` 字体配置；
- TIFF 结果体积约 105 MB，复制和打开较慢；
- 代码中部分旧脚本硬编码了 `d:\resources\pythonTest\...` 路径，换机器后需逐一修改。

## 8. 常见问题与故障排除

| 问题 | 原因 | 解决 |
|---|---|---|
| `No module named torch/pandas/pywt` | 依赖未安装或环境未激活 | `conda activate chicken_warn` 后重装 `requirements.txt` |
| `No Python at 'C:\Users\...\python.exe'` | 原 `venv` 绑定到别的机器 | 删除原 `venv`，新建 conda 环境 |
| `FileNotFoundError: 最后三天测试.csv` | 数据被清理或路径未改 | 从回收站恢复数据，或修改 `data_file` |
| 中文显示为方块 | 缺少中文字体 | 安装 SimHei/微软雅黑，或修改 `plt.rcParams['font.family']` |
| `SyntaxError: unterminated string literal` | 打开了残缺脚本 `gen_framework.py` / `generate_svgs.py` | 改用 `make_svgs.py` |
| `RuntimeError: CUDA out of memory` | GPU 显存不足 | 设置 `device='cpu'` 或减小 batch_size |
| 评估指标全为 1.0 | 预警标签口径过于宽松 | 见 `08_已知问题与待补项.md`，需人工复核阈值 |
