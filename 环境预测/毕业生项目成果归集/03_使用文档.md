# 使用文档

> 面向对象：养殖户、评审老师、模型调用开发者。本文不涉及代码细节，只讲“这个系统能干什么、怎么用、看到结果后怎么判断”。

## 1. 系统能做什么

本系统面向鸡舍环境管理，主要做三件事：

1. **提前预警**：根据最近的环境数据，预测未来 30 分钟的温度偏差 TD 和温湿指数 THI；
2. **判断异常**：判断鸡舍是偏热、偏冷还是正常，以及 THI 处于舒适、警告、危险还是紧急等级；
3. **留痕与评估**：把每一步预测和预警写入 CSV，并生成可视化图，方便复盘和评估。

## 2. 使用前准备

- 已按 `02_部署文档.md` 配好 Python 环境；
- 已准备好环境数据 CSV，字段至少包含：`日期`、`日龄`、`目标温度`、`当前温度`、`外界温度`、`相对湿度`、`温度偏差`、`THI`、`CO2`；
- 数据文件编码支持 GBK / UTF-8；脚本会自动尝试多种编码。

## 3. 角色与功能

| 角色 | 可做操作 | 入口 |
|---|---|---|
| 普通用户 / 评审老师 | 查看框架图、查看示例结果图、运行一次完整仿真 | `图文/framework_diagram.svg`、`图文/warning_simulation_result.png`、`源码/warning_simulation_v2.py` |
| 系统管理员 | 修改预警阈值、修改数据路径、重新运行评估 | `源码/monitoring_warning_system.py`、`源码/warning_simulation_v2.py` |
| 模型调用开发者 | 加载 `.pth` 权重，对自有数据做推理 | `源码/warning_simulation_v2.py` 中的 `load_model` / `batch_predict` |

系统没有登录注册功能，所有角色通过脚本权限控制。

## 4. 快速入门

### 4.1 打开展示页面

双击 `源码/monitoring_system.html`，浏览器会显示“鸡舍环境实时监测与预警系统”静态页面。该页面用于展示设计与说明，不连接实时设备。

### 4.2 运行一次完整仿真

在归集包根目录打开终端：

```bash
conda activate chicken_warn
python 源码/warning_simulation_v2.py
```

运行结束后会得到：

- `warning_simulation_result.png`：四子图结果；
- `warning_simulation_result.tiff`：高清版结果图；
- `warning_simulation_log.csv`：逐步预警记录。

### 4.3 查看评估结果

```bash
python 源码/eval_warning_v2.py
```

生成/更新：

- `warning_metrics_result.csv`：R2、MAE、RMSE、F1 等指标；
- `warning_simulation_log_with_levels.csv`：带预测等级和实际等级的明细。

## 5. 结果怎么看

### 5.1 四子图含义

| 子图 | 内容 |
|---|---|
| TD 预测曲线 | 蓝线为实际/目标温度偏差，红线为模型预测，虚线为偏热/偏冷阈值 |
| THI 预测曲线 | 展示 THI 预测与实际的对比，标出 70/76/81 分级线 |
| TD 预警状态 | 用颜色标注正常、偏热、偏冷区间 |
| THI 风险等级 | 用不同颜色标注舒适、警告、危险、紧急 |

### 5.2 预警日志字段说明

| 字段 | 含义 |
|---|---|
| `当前时间` | 采集/当前时刻 |
| `预测时间` | 提前 30 分钟对应的预测时刻 |
| `日龄` | 肉鸡日龄，决定适宜温度区间 |
| `TD预测` / `TD实际` | 温度偏差预测值与实测值 |
| `THI预测` / `THI实际` | 温湿指数预测值与实测值 |
| `TD状态` | 正常 / 偏热 / 偏冷 |
| `THI等级` | 0 舒适、1 警告、2 危险、3 紧急 |
| `触发预警` | True 表示需要人工干预 |
| `预警类型` | 例如“THI警告”“偏热预警” |

完整字段见 `05_数据与数据字典.md`。

## 6. 指标怎么理解

| 指标 | 含义 | 直观理解 |
|---|---|---|
| R2 | 拟合优度 | 越接近 1 越好 |
| MAE | 平均绝对误差℃ | 越小越好，例如 TD MAE≈0.20℃ |
| RMSE | 均方根误差 | 对大误差更敏感 |
| Precision | 预警准确率 | 报出去的预警里有多少是真异常 |
| Recall | 预警召回率 | 真异常里有多少被抓到 |
| F1 | Precision 与 Recall 的调和平均 | 综合指标 |

> 注意：当前评估中“综合预警二分类”结果为 596 个样本全部被判为预警，因此 Accuracy=1.0 不具备实际评审说服力，需人工复核口径。详见 `08_已知问题与待补项.md`。

## 7. 常见操作

### 7.1 换一份数据测试

1. 把新 CSV 放到 `数据/` 目录；
2. 打开 `源码/warning_simulation_v2.py`，修改第 575 行 `data_file`；
3. 确认字段至少包含第 2 节列出的列；
4. 重新运行脚本。

### 7.2 修改预警阈值

- TD 固定阈值：`源码/monitoring_warning_system.py` 中 `TD_HOT_THRESHOLD`、`TD_COLD_THRESHOLD`；
- THI 固定分级：同文件 `THI_COMFORT_MAX`、`THI_ALERT_MAX`、`THI_WARNING_MAX`；
- 主脚本动态 TD 阈值：`warning_simulation_v2.py` 中 `WARN_MARGIN` 与 `classify_td()`；
- 主脚本 THI 分级：`warning_simulation_v2.py` 中 `classify_thi()`（70/76/81）。

修改后需重新运行仿真才能看到效果。

### 7.3 只看示意图

打开 `图文/framework_diagram.svg` 或 `图文/multi_model_comparison.png`，无需运行任何程序。

## 8. 常见问题

| 现象 | 可能原因 | 处理方式 |
|---|---|---|
| 提示找不到 CSV | 数据路径未改或文件被移走 | 修改脚本中的 `data_file` |
| 提示找不到 `.pth` | 未从归集包根目录运行 | 在包根目录执行命令，或改用绝对路径 |
| 图里中文是方块 | 系统缺中文字体 | 安装 SimHei/微软雅黑 |
| 运行很慢 | TIFF 高清图写入耗时 | 先注释掉 TIFF 保存语句 |
| 指标看起来过高 | 预警标签口径宽松 | 参考 `08_已知问题与待补项.md` 复核 |
| 想直接看网页 | 静态 HTML 不连模型 | 只能查看展示页，实际预测需运行 Python 脚本 |
