鸡舍环境实时预警系统 - 实现方案文档
================================================================================

## 系统概述

基于TD（温度偏差）和THI（温湿度指数）的双指标预警系统，采用Wavelet-ECA-GRU模型进行
5分钟时间步长的滚动预测，提前30分钟识别鸡舍环境异常。

## 核心功能模块

### 1. 数据预处理模块
- 多源数据对齐：巡检机器人、舍内固定点、室外监测点
- 时间戳对齐与5分钟等间隔重采样
- 缺失值处理（插值+前后填充）
- 小波分解特征提取（仅对目标变量）

### 2. 模型加载与推理
- 加载两个预训练模型：
  * TD模型：温度偏差预测
  * THI模型：温湿度指数预测
- 模型架构：Wavelet-ECA-GRU
  * ECA层：通道注意力机制
  * GRU层：时序特征学习
  * 输出层：单步预测

### 3. 滚动预测策略
- 输入窗口：36个时间步 × 5分钟 = 180分钟历史数据
- 预测范围：6个时间步 × 5分钟 = 30分钟未来数据
- 滑动步长：1个时间步（5分钟）
- 实时更新：与采样节拍一致

### 4. 双指标预警机制

#### TD预警规则（温度偏差）
- 偏热预警：TD > 2.5℃
  * 表示鸡舍温度高于目标温度2.5℃以上
  * 需要启动降温措施（通风、喷雾等）
  
- 偏冷预警：TD < -2.5℃
  * 表示鸡舍温度低于目标温度2.5℃以上
  * 需要启动升温措施（供暖）
  
- 正常状态：-2.5℃ ≤ TD ≤ 2.5℃

#### THI预警规则（温湿度指数）
- 正常级：THI ≤ 74
  * 鸡群处于舒适环境
  
- 警戒级：74 < THI ≤ 78
  * 鸡群开始感受热应激
  * 建议加强通风
  
- 预警级：78 < THI ≤ 82
  * 鸡群明显热应激
  * 需要立即采取降温措施
  
- 危急级：THI > 82
  * 鸡群严重热应激
  * 需要紧急干预

### 5. 预警输出策略

#### 单指标预警
- 仅TD超阈值：输出"偏冷预警"或"偏热预警"
- 仅THI超阈值：输出"THI警戒/预警/危急"

#### 双指标联合预警
- 同时满足两类预警条件时，同步输出对应预警信息
- 优先级：危急 > 预警 > 警戒 > 正常

## 预警统计指标

- 总预测步数：N
- 触发预警步数：M
- 预警率：M/N × 100%
- TD偏热预警次数
- TD偏冷预警次数
- THI警戒级次数
- THI预警级次数
- THI危急级次数

## 系统优势

1. **提前预测**：提前30分钟识别异常，为环境调控提供决策依据
2. **双指标融合**：从环境控制偏差和综合热环境风险两个维度评估
3. **实时滚动**：与采样节拍一致，无延迟
4. **模型融合**：结合小波分解、ECA注意力和GRU时序学习
5. **可解释性**：清晰的阈值规则和预警等级

## 应用场景

- 自动化通风控制：根据TD预警调整通风量
- 供暖系统控制：根据TD预警启动/关闭供暖
- 降温系统控制：根据THI预警启动喷雾/冷却
- 环境监测告警：实时推送预警信息到管理系统
- 数据分析：记录预警历史，优化环境控制策略

## 文件输出

1. warnings_log.csv - 预警日志（包含所有预测步骤的详细信息）
2. warning_predictions.png - 预测结果可视化图表
   - 子图1：TD预测值与阈值

## 使用方法

```python
# 初始化系统
system = WarningSystem(
    td_model_path="温度偏差预测/gru+小波+eca/Model_GRUWavelet_no_leakage_pytorch.pth",
    thi_model_path="THI/pth/Model_GRUWavelet_no_leakage_pytorch.pth",
    data_path="THI/温湿度数据.csv"
)

# 执行预测
predictions = system.rolling_predict(start_idx=0, num_steps=500)

# 输出结果
system.print_warning_summary()
system.print_warning_details(num_samples=15)
system.plot_predictions()
system.save_warnings_to_csv()
```

## 注意事项

1. 确保两个模型的输入维度一致
2. 数据需要包含必要的特征列（温度、湿度、日龄等）
3. 时间戳需要正确对齐
4. 预测结果需要反归一化到实际物理量
5. 阈值可根据实际鸡舍条件调整
