# 数据与数据字典

## 1. 数据概述

本项目数据来自鸡舍环境传感器采集的时序记录，采样间隔约 5 分钟。数据以 CSV 文件存放，未使用数据库。

| 类别 | 文件（本包路径） | 行数 | 字段数 | 编码 | 用途 |
|---|---|---:|---:|---|---|
| 模型训练初始数据 | `数据/温湿度数据111.csv` | 8,458 | 13 | GBK | 训练、相关性分析、周趋势绘图 |
| 测试/新数据 | `数据/部分温湿度数据.csv` | 1,603 | 11 | GBK | 模型推理、推理脚本测试 |
| 仿真日志 | `数据/warning_simulation_log.csv` | 596 | 17 | UTF-8-SIG | 逐步预测与预警记录 |
| 带等级明细 | `数据/warning_simulation_log_with_levels.csv` | 596 | 23 | UTF-8-SIG | 预测/实际等级逐条核对 |
| 评估指标 | `数据/warning_metrics_result.csv` | 24 | 3 | UTF-8-SIG | R2/MAE/RMSE/F1 等结果 |

本包共复制了 51 个 CSV（约 9.89 MB），包含各模型目录中的训练/测试数据副本和实验输出。各子目录中的 `温湿度数据.csv`、`部分温湿度数据.csv` 是对应脚本按相对路径运行时所需的数据副本，请勿随意删除。

## 3. 标注数据说明

本项目是**回归预测 + 规则判级**任务，训练标签来自传感器记录本身：

- TD 标签：`温度偏差` 列；
- THI 标签：`THI` 列；
- 预警等级标签：由阈值规则计算得到，不是人工标注。

因此没有 LabelImage / LabelStudio 等标注工具，也没有 JSON/XML 标注文件。PDF 中“标注数据”和“标注工具使用文档”对本课题**不适用**。

## 4. 数据结构详情

### 4.1 训练/测试数据字段

| 字段名 | 类型 | 含义 | 单位/范围 |
|---|---|---|---|
| 日期 | string | 采集时间 | `2025/5/26 8:22` 格式 |
| 日龄 | int | 肉鸡日龄 | 5~45 等 |
| CO2 | float | 鸡舍 CO2 浓度 | ppm |
| 当前负压 | int | 鸡舍负压 | — |
| 目标温度 | float | 目标设定温度 | ℃ |
| 当前温度 | float | 实测温度 | ℃ |
| 外界温度 | float | 室外温度 | ℃ |
| 相对湿度 | int | 舍内相对湿度 | % |
| 温度偏差 | float | 当前温度 − 目标温度 | ℃ |
| 风速 | float | 舍内风速 | m/s |
| THI | float | 温湿指数 | 无量纲，约 70~90 |
| 室外湿度 | float | 室外相对湿度（仅训练数据有） | % |
| 室外风速 | float | 室外风速（仅训练数据有） | m/s |

`部分温湿度数据.csv` 比 `温湿度数据111.csv` 少 `室外湿度`、`室外风速` 两列。

### 4.2 仿真日志字段

| 字段名 | 含义 |
|---|---|
| step | 步序号 |
| 当前时间 | 当前采样时刻 |
| 预测时间 | 提前 30 分钟对应的预测时刻 |
| 日龄 | 肉鸡日龄 |
| 目标温度 | 设定目标温度 |
| TD预测 / TD实际 | 温度偏差预测/实测 |
| THI预测 / THI实际 | 温湿指数预测/实测 |
| TD偏热阈值 / TD偏冷阈值 | 由日龄适宜温度区间换算的阈值 |

## 5. 数据质量说明

- 采集数据存在缺失值，训练与推理脚本中均包含缺失值处理逻辑；
- CSV 编码不统一：训练/测试数据多为 GBK，日志与指标为 UTF-8-SIG；`debug_csv.py` 用于探测编码；
- 时间戳字段在部分脚本中被重命名为 `时间戳`，另一部分保留 `日期`；
- 不同脚本的列数假设不同：10 列与 11 列格式均有兼容代码；
- 数据按时间顺序排列，训练/测试划分按时间段而非随机打乱，避免时间泄漏。

## 6. 数据预处理说明

1. **编码探测**：依次尝试 GBK、UTF-8、UTF-8-SIG、GB18030；
2. **列名统一**：中文列名重命名为英文缩写或统一中文名；
3. **缺失值处理**：按列填充或删除缺失样本（具体见各脚本）；
4. **小波分解**：仅对目标列做滑动窗口 db4 三层分解，窗口长度 36，保证不使用未来信息；
5. **归一化**：`MinMaxScaler` 仅在训练集上拟合，再应用到验证/测试/新数据；
6. **序列构造**：按 `time_step=36`、`pred_offset=6` 构造输入窗口与标签。

## 7. 命名规范与索引策略

- 数据表即 CSV 文件，文件名采用中文业务命名或 `warning_xxx.csv` 英文命名；
- 字段采用中文业务名称，未使用数据库风格的小写下划线命名；
- 无数据库索引、外键、约束或存储过程；
- 时间序列以文件行顺序和 `日期` 字段作为逻辑顺序。

## 8. 数据迁移与备份

- 前面的注释前备份 zip 已不在工作区，去向不明，请勿依赖它。
